# The Village Below

Target: 15–20 minute horror mining-village adventure, one or two players, solo-first. Gate → square → survivor → blacksmith investigation → road puzzle → mine checkpoint/cutscene → ambush → two-phase spatial boss → ending. Church is optional lore/preparation. The village deliberately sealed something underground.

Ivan owns creative direction, pacing/fun, canonical art choices, final polish and publication. Codex implements local authoring, safe construction, gameplay configuration, tests and packaging. No automatic publication or SaaS work.
