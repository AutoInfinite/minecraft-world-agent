# Asset registry

`worldagent:seal` aliases the Minecraft client's existing ambient/cave/cave1 sound. No Mojang sound file is copied or redistributed. Croatian and English subtitles are included. This is a small custom namespace pack with a vanilla audio fallback, not newly composed audio. Format 88.0 is pinned to Java 26.2: https://feedback.minecraft.net/hc/en-us/articles/46690753273997-Minecraft-Java-Edition-26-2
